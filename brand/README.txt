Исходники оформления. Эта папка не публикуется — сайт раздаётся из docs/.

«Логотип 3. png.png» — исходный логотип колледжа.
Из него собираются картинки сайта:

    python tools/make_logo.py "brand/Логотип 3. png.png"

Скрипт кладёт в docs/assets четыре файла: logo.png (шапка),
favicon.png (вкладка браузера), icon-192.png и icon-512.png
(установка как приложения).

icon-student.png — картинка студента, которую скачивали для карточки.
Сейчас не используется: карточки «Я студент» и «Я преподаватель» без иконок.
