Исходники оформления. Эта папка не публикуется — сайт раздаётся из docs/.

«Логотип 3. png.png» — исходный логотип колледжа.
Из него собираются картинки сайта:

    python tools/make_logo.py "brand/Логотип 3. png.png"

Скрипт кладёт в docs/assets четыре файла: logo.png (шапка),
favicon.png (вкладка браузера), icon-192.png и icon-512.png
(установка как приложения). Пятый, docs/favicon.ico, ложится в корень
сайта — за ним ходят поисковики, чтобы нарисовать значок в выдаче.

icon-student.png — картинка студента, которую скачивали для карточки.
Не пригодилась: на карточках стоят значки из набора Phosphor Icons.

Значки «Я студент» и «Я преподаватель» — student и chalkboard-teacher
из набора Phosphor Icons, https://phosphoricons.com. Лежат не файлами,
а прямо в разметке docs/index.html. Лицензия MIT, её текст:
https://github.com/phosphor-icons/core/blob/main/LICENSE — если когда-нибудь
значки поедут отдельными файлами, текст лицензии должен ехать с ними.
